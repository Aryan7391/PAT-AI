# Voice Command Module

## 🎤 Overview
The Voice Command module allows users to interact with the system using voice commands, providing a hands-free experience.

## 🚀 Features
- **Speech Recognition:** High accuracy in recognizing speech.
- **Voice Feedback:** Provides audio feedback for user commands.
- **Multi-Language Support:** Supports commands in multiple languages.

## 📦 Installation
To install the Voice Command module, use the following command:

```bash
pip install voice-command
```

## ⚙️ Usage
Import the module and start using it:

```python
from voice_command import VoiceCommand

vc = VoiceCommand()
vc.start_recognition()
```

## 📝 Example Commands
- `Play Music`
- `Stop the Music`
- `Skip to Next Track`

## 🔧 Configuration
Configure the module via config.json: 

```json
{
    "language": "en",
    "voice_feedback": true
}
```
